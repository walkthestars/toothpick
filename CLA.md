## 10. How to Sign

Signatures are collected per contributor (not per pull request). A
first-time contributor signs once by commenting the following exact phrase on
their pull request:

    I have read the CLA Document and I hereby sign the CLA

The signature is then recorded automatically by the repository's CLA workflow
and stored with the contributor's GitHub identity and the date of signing.
The signature covers that contributor's present and future Contributions to
the Project, including the Contributions submitted in the pull request in
which you sign, from the moment the signature is recorded. Contributions
submitted before you sign this Agreement — except those in the pull request
in which you sign — are not covered by it at the time of submission; they
become covered automatically if and when you sign, and the Project Owner
will not incorporate such Contributions until you have signed. Because the
signature is per contributor and not per channel, Contributions submitted by
other means (for example, in an issue) are likewise covered once you have
signed through the pull-request mechanism described above. The signature is
stored as a JSON record with your GitHub identity and the date of signing on
a public branch of the Project's repository (presently `cla-signatures`),
where it remains permanently auditable. The version of this Agreement in
force for a contributor is the version in force when the signature was
recorded; the repository's git history of this file
provides the authoritative version timeline. See `CONTRIBUTING.md` for
details on how signatures are collected and audited.
